## What it does

`main.py` writes a single sentence — one bizarre startup pitch, at most 200
characters — to `/output/entry.txt`. Deterministic, no network, no input.

## The pitch

> We rent goats in tuxedos to attend corporate layoff meetings, and HR departments pay $800 a day because nobody films themselves crying when a goat in a bow tie is eating the severance paperwork.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
